# Project-Template

Template for automated github projects

# GitHub Project Automation

## Required Secret

PROJECT_TOKEN

Token permissions:
- repo
- project

## Configuration

PROJECT_OWNER:
Your GitHub username

PROJECT_NUMBER:
Your project number. You can find this via going to you project and looking at the end of the URL. If it isn't a number this won't work.

STATUS_FIELD_NAME:
Usually Status

IN_PROGRESS_OPTION_NAME:
Usually In progress
